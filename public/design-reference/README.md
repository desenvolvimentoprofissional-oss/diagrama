# Referência visual institucional

As páginas de referência foram extraídas do documento aprovado **Versão Editada Final.pdf**, disponível
no repositório institucional `Site---Configura-es/docs/pdp`. Servem para demonstrar hierarquia,
proporções, tipografia, identidade, composição e infográficos. Seu conteúdo não deve ser usado como
fonte de fatos, regras ou exemplos normativos em outro documento.

- `chapter.jpg`: capítulo e hierarquia de leitura.
- `access-map.jpg`: comparação estruturada de condições.
- `decision.jpg`: percurso com alternativas e convergência.
- `process.jpg`: fluxo de responsabilidades.
- `glossary.jpg`: tabela de consulta.
- `cover-art.jpg`: camada decorativa da capa aprovada, com fotografia, marca e grafismos. O título
  original foi retirado de uma cópia em memória. O título e o subtítulo do novo documento são
  acrescentados como texto nativo editável, inclusive na exportação Word.

O PDF aprovado permanece inalterado. As referências são assets locais: nenhum endereço externo é
consultado para compor as páginas.
